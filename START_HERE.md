## 🎯 En 3 Minutos

### 1️⃣ Instalar dependencias
```bash
npm install
```

### 2️⃣ Ejecutar localmente
```bash
npm run dev
```
Abre: **http://localhost:3000**

### 3️⃣ Editar contenido
Abre `public/index.html` y modifica:
- Títulos
- Precios
- Testimonios
- Información de contacto
